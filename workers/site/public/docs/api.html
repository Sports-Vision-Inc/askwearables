API reference

A broker between wearable data and AI agents. Ask a question; receive a small computed context packet at the level the user's grant allows. Developer requests are signed: HMAC-SHA256 over timestamp\nnonce\nMETHOD\npath\nsha256(body) with your signing secret, a single-use nonce and a 300-second window.

Base URLhttps://api.askwearables.app
VersionAskWearables API 1.0.0, OpenAPI 3.1.0
AuthenticationAn OAuth access token for an agent, or an API key: aw_own_ (owner), aw_dev_ (developer), aw_sync_ (device sync).
Machine-readableopenapi.json

Each endpoint lists the credentials that can call it. Errors and gate decisions are described in the overview, and the packet in packets and levels.
